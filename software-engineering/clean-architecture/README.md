# Clean Architecture

### Purpose
Part of the [Software Engineering Principles](..) domain, this directory explores concentric, domain-centric architecture that isolates core business logic from frameworks, UI, and external data sources. It promotes high testability and architectural longevity.

### Scope
Topics include the Dependency Inversion principle across layers, Domain/Application/Infrastructure/Presentation separation, Ports and Adapters (Hexagonal Architecture), and DTO mapping.

### Content Guidelines
Document project reference hierarchies in .NET solutions, use case encapsulation, domain independence validation, and testability benefits of concentric layering.
