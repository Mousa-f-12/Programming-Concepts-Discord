# Code Review Standards

### Purpose
Part of the [Software Engineering Principles](..) domain, this directory outlines peer code review processes, pull request guidelines, and constructive engineering feedback practices. It fosters collective code ownership and shared quality standards.

### Scope
Topics include pull request sizing, automated linter/analyzer integration, review checklists (security, performance, correctness), constructive feedback etiquette, and review turnaround SLAs.

### Content Guidelines
Document code review guidelines for team alignment, automated CI gating before review, common anti-patterns in review comments, and knowledge-sharing best practices.
