# SOLID Principles and Design Patterns

### Purpose
Part of the [Software Engineering Principles](..) domain, this directory explores structural and behavioral design heuristics that foster decoupled, extensible, and maintainable software systems. It bridges foundational principles and proven structural solutions.

### Scope
Topics span the five SOLID principles (SRP, OCP, LSP, ISP, DIP) and Gang of Four (GoF) structural, creational, and behavioral design patterns.

### Content Guidelines
Document practical pattern applications in modern C#, pattern anti-patterns, over-engineering warning signs, and refactoring pathways toward SOLID compliance.
