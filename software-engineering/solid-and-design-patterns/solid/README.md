# SOLID Principles

### Purpose
Located within [SOLID and Design Patterns](..), this directory focuses on the five core object-oriented design principles formulated to make software designs more understandable, flexible, and maintainable. It details the heuristics that prevent rigid code.

### Scope
Topics include Single Responsibility Principle (SRP), Open/Closed Principle (OCP), Liskov Substitution Principle (LSP), Interface Segregation Principle (ISP), and Dependency Inversion Principle (DIP).

### Content Guidelines
Document violation detection heuristics, concrete refactoring examples in C#, boundary trade-offs, and practical application within modern microservices and libraries.
