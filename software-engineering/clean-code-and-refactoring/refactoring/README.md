# Code Refactoring Techniques

### Purpose
Located within [Clean Code and Refactoring](..), this directory explores safe, disciplined transformations of existing code structures to enhance maintainability and extensibility. It targets reducing technical debt while preserving behavior.

### Scope
Topics include Fowler\'s refactoring catalog (Extract Method, Move Class, Replace Conditional with Polymorphism), code smell catalogs, refactoring with unit test coverage, and legacy code modernization.

### Content Guidelines
Document step-by-step refactoring workflows, characterization testing before refactoring, safe tooling in Visual Studio and Rider, and legacy debt remediation.
