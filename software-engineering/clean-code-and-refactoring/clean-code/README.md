# Clean Code Practices

### Purpose
Located within [Clean Code and Refactoring](..), this directory details software readability standards, expressive coding techniques, and simplicity in daily software construction. It reduces cognitive friction during code maintenance.

### Scope
Topics include intention-revealing naming, small focused functions, side-effect minimization, comment necessity versus self-documenting code, and clean error handling.

### Content Guidelines
Document idiomatic formatting conventions, cognitive complexity reduction, clean class structure, and pragmatic readability trade-offs in .NET codebases.
