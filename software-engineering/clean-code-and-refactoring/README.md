# Clean Code and Refactoring

### Purpose
Part of the [Software Engineering Principles](..) domain, this directory focuses on code readability, cognitive load reduction, and structured techniques for improving existing software design without altering behavior. It supports sustainable long-term development.

### Scope
Topics span naming conventions, method decomposition, code smell identification, technical debt management, automated refactoring patterns, and maintainability metrics.

### Content Guidelines
Document refactoring strategies for legacy codebases, cyclomatic complexity reduction, readability guidelines, and code transformation checklists.
