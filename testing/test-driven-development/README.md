# Test-Driven Development (TDD)

### Purpose
Part of the [Software Testing](..) domain, this directory explores the Red-Green-Refactor cycle and design-driven testing methodology in software development. It advocates using tests to drive clear interface design.

### Scope
Topics include the Red-Green-Refactor rhythm, emergent architecture, test-first versus test-after trade-offs, behavior-driven development (BDD), and transformation priority premises.

### Content Guidelines
Document practical TDD workflows, test granularity heuristics, refactoring under green test suites, and common adoption challenges in enterprise teams.
