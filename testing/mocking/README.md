# Test Doubles & Mocking

### Purpose
Part of the [Software Testing](..) domain, this directory explores the theory and implementation of test doubles used to isolate units under test from external dependencies. It helps write fast, deterministic test suites.

### Scope
Topics include Dummies, Stubs, Spies, Mocks, and Fakes, mocking libraries (Moq, NSubstitute, FakeItEasy), auto-mocking containers, and state versus interaction testing.

### Content Guidelines
Document appropriate mocking boundaries, over-mocking anti-patterns, verifiable test double design, and performance overheads of dynamic mock generation.
