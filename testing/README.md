# Software Testing & Quality Assurance

### Purpose
This domain centralizes methodologies, frameworks, and best practices for verifying backend application correctness, performance, and contract compliance. It provides the foundation for confident, automated software delivery.

### Scope
Topics encompass unit testing, integration testing, API contract testing, test doubles and mocking, and Test-Driven Development (TDD).

### Content Guidelines
Store test strategy documents, coverage criteria, testing pyramid models, test data management practices, and automated pipeline test configurations.
