# API & Contract Testing

### Purpose
Part of the [Software Testing](..) domain, this directory focuses on end-to-end endpoint verification, contract testing, and black-box validation of HTTP and gRPC backend interfaces. It verifies that service boundaries honor client expectations.

### Scope
Topics include integration testing with `WebApplicationFactory`, REST API contract testing (Pact), schema validation, status code/payload assertion, and external dependency stubs.

### Content Guidelines
Document automated API test suite design, wiremock usage for external services, schema drift detection, and CI integration for automated endpoint regression tests.
