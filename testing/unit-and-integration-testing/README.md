# Unit and Integration Testing

### Purpose
Part of the [Software Testing](..) domain, this directory addresses automated code verification across isolated component boundaries and composite multi-component interactions. It covers the core layers of the testing pyramid.

### Scope
Topics include testing frameworks (xUnit, NUnit, MSTest), assertion libraries (FluentAssertions), test lifecycle hooks, test fixtures, and execution parallelism.

### Content Guidelines
Store framework configuration guidelines, test execution performance tuning, test isolation best practices, and CI test runner optimizations.
