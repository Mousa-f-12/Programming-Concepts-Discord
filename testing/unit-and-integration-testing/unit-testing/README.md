# Unit Testing

### Purpose
Located within [Unit and Integration Testing](..), this directory covers automated verification of isolated, fine-grained units of code in complete isolation from external resources. It guarantees low-level algorithm correctness.

### Scope
Topics include test structure (Arrange-Act-Assert), deterministic testing, edge case coverage, fast execution mechanics, parameterized testing (`[Theory]`), and code coverage metrics.

### Content Guidelines
Document unit test naming conventions, mutation testing principles, boundary condition verification, and guidelines for writing maintainable test code.
