# Integration Testing

### Purpose
Located within [Unit and Integration Testing](..), this directory focuses on validating multi-component workflows, database persistence, and external service contracts in unified environments. It verifies that subsystems function cohesively together.

### Scope
Topics include ASP.NET Core `WebApplicationFactory`, real-database testing with Testcontainers, database migration testing, transaction rollbacks between tests, and state isolation.

### Content Guidelines
Document integration test container orchestration, database seeding and cleanup strategies, fast execution techniques, and isolation from live third-party dependencies.
