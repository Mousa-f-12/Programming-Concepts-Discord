# Operating Systems Concepts

### Purpose
Part of the [Computer Science Foundations](..) domain, this directory focuses on operating system architecture, resource scheduling, and the boundary between user-space applications and the kernel. It details how the OS manages hardware resources.

### Scope
Topics include process and thread lifecycles, CPU scheduling algorithms, system calls, inter-process communication (IPC), file system internals, and I/O multiplexing (`epoll`, `kqueue`).

### Content Guidelines
Document kernel context switch costs, user/kernel space transitions, signal handling, and hardware abstraction mechanisms across Linux and Windows.
