# Algorithms

### Purpose
Part of the [Computer Science Foundations](..) domain, this directory covers fundamental computational algorithms, complexity theory, and problem-solving strategies. It provides the analytical tools to evaluate algorithmic efficiency.

### Scope
Topics include sorting and searching algorithms, graph traversal (BFS, DFS, Dijkstra), dynamic programming, divide-and-conquer, greedy algorithms, and asymptotic notation (Big-O, Big-Theta).

### Content Guidelines
Document algorithmic efficiency trade-offs, space-time complexities, edge-case behavior, and practical backend algorithmic applications.
