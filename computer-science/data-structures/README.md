# Data Structures

### Purpose
Part of the [Computer Science Foundations](..) domain, this directory outlines fundamental and advanced data structures used to organize, store, and manipulate data in memory. It establishes the building blocks for performant software design.

### Scope
Topics include arrays, linked lists, binary search trees, AVL trees, red-black trees, hash tables, heaps, tries, graphs, and disjoint-set structures.

### Content Guidelines
Document structural invariant proofs, memory layout implications, Big-O access and mutation complexities, and appropriate data structure selection guidelines.
