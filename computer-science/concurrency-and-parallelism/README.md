# Concurrency and Parallelism Foundations

### Purpose
Part of the [Computer Science Foundations](..) domain, this directory focuses on the theoretical and systems-level foundations of concurrent execution and multi-core computation. It addresses the challenges of coordinating simultaneous tasks.

### Scope
Topics span race conditions, deadlocks, livelocks, synchronization primitives (mutexes, semaphores, spinlocks), memory visibility, and CPU cache coherency.

### Content Guidelines
Store theoretical execution models, hardware memory models, lock-free synchronization theories, and architectural concurrency paradigms.
