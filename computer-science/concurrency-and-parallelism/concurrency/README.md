# Concurrency Concepts

### Purpose
Located within [Concurrency and Parallelism](..), this directory explores the composition of independently executing processes and interleaved execution models. It focuses on managing multiple tasks making progress over shared resources.

### Scope
Topics include time-slicing, context switching, cooperative multitasking, event loops, mutual exclusion, and actor-based concurrency models.

### Content Guidelines
Document synchronization barriers, critical section protection, deadlock avoidance algorithms (such as the Banker\'s algorithm), and thread coordination theory.
