# Containerization with Docker

### Purpose
Part of the [Tools, DevOps & Infrastructure](..) domain, this directory focuses on packaging .NET applications into lightweight, immutable, and portable container images. It covers reproducible runtime environments across platforms.

### Scope
Topics include multi-stage Dockerfiles for .NET, base image selection (chiseled/Alpine versus Debian), layer caching optimization, non-root user execution, and container resource limits.

### Content Guidelines
Document minimal image footprint techniques, container security hardening, environment variable injection, and local multi-container development with Docker Compose.
