# Linux for .NET Backend Engineering

### Purpose
Part of the [Tools, DevOps & Infrastructure](..) domain, this directory covers Linux operating system fundamentals, system administration, and performance diagnostic tools for hosting .NET Core applications. It details running .NET in Linux environments.

### Scope
Topics include systemd service management, bash scripting, file permissions, networking diagnostics (`curl`, `netstat`, `tcpdump`), process inspection (`htop`, `ps`), and .NET global tools on Linux (`dotnet-dump`, `dotnet-trace`).

### Content Guidelines
Document production Linux daemon configurations, crash dump generation and analysis, memory leak diagnostics on Linux, and container host performance tuning.
