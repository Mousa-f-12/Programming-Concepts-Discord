# Tools, DevOps & Infrastructure

### Purpose
This domain outlines operational workflows, build automation, containerization, hosting infrastructure, and observability tooling for .NET backends. It bridges development and operational environments for reliable production delivery.

### Scope
Topics encompass version control (Git/GitHub), containerization (Docker), Linux server administration, Continuous Integration/Continuous Deployment (CI/CD), deployment topologies, and monitoring/logging platforms.

### Content Guidelines
Store infrastructure-as-code manifests, container hardening blueprints, pipeline configurations, operational runbooks, and telemetry dashboards.
