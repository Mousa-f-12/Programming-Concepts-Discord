# Git Version Control & GitHub Workflows

### Purpose
Part of the [Tools, DevOps & Infrastructure](..) domain, this directory outlines distributed version control practices, repository management, and collaboration workflows using Git and GitHub. It fosters consistent source code collaboration.

### Scope
Topics include Git branching strategies (GitHub Flow, Trunk-Based Development), commit message conventions (Conventional Commits), merge versus rebase mechanics, pull request automation, and GitHub branch protection rules.

### Content Guidelines
Document repository collaboration standards, submodule/monorepo management, Git conflict resolution, and secret scanning configurations.
