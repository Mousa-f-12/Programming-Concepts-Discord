# Continuous Integration & Continuous Deployment (CI/CD)

### Purpose
Part of the [Tools, DevOps & Infrastructure](..) domain, this directory covers automated build, test, and release pipelines for reliable, frequent software delivery. It emphasizes rapid feedback and automated verification gates.

### Scope
Topics include GitHub Actions, Azure Pipelines, automated testing gates, semantic versioning, artifact packaging (NuGet, container images), and deployment automation.

### Content Guidelines
Document pipeline workflow templates, caching strategies for NuGet packages, multi-stage release gates, rollback triggers, and pipeline security practices.
