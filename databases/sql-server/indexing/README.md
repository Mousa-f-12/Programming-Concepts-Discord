# SQL Server Indexing Architecture

### Purpose
Located within [Microsoft SQL Server](..), this directory explores B-tree index structures, storage mechanics, and indexing strategies for SQL Server query acceleration. It provides guidance on optimizing physical access paths.

### Scope
Topics include clustered versus non-clustered indexes, covering indexes (`INCLUDE` columns), filtered indexes, columnstore indexes, index fragmentation, and statistics histograms.

### Content Guidelines
Document B-tree node navigation, index key column ordering rules, write-amplification trade-offs, index maintenance strategies, and missing index Dynamic Management Views (DMVs).
