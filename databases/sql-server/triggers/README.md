# SQL Server Triggers

### Purpose
Located within [Microsoft SQL Server](..), this directory explores DML and DDL event-driven trigger mechanisms in Microsoft SQL Server. It outlines when and how to implement automated database-level reactions.

### Scope
Topics include `AFTER` triggers, `INSTEAD OF` triggers, the virtual `inserted` and `deleted` tables, recursive trigger configuration, and auditing triggers.

### Content Guidelines
Document multi-row trigger execution safety, performance overheads of synchronous trigger execution, unintended transaction rollbacks, and alternative event-driven solutions.
