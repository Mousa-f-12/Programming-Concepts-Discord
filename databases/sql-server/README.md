# Microsoft SQL Server Engine

### Purpose
Part of the [Databases & Data Persistence](..) domain, this directory focuses on Microsoft SQL Server architecture, storage engine internals, and query execution mechanics. It examines the relational database engine commonly paired with .NET backends.

### Scope
Topics encompass T-SQL programming, stored procedures, user-defined functions, DML triggers, index architectures, execution plan analysis, and transaction management.

### Content Guidelines
Store SQL Server storage engine documentation (pages, extents, allocation maps), engine-specific features, latch/lock internals, and administrative guidelines.
