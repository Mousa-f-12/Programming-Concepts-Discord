# SQL Server Transactions & Concurrency

### Purpose
Located within [Microsoft SQL Server](..), this directory focuses on ACID transaction semantics, locking protocols, and transaction isolation levels in SQL Server. It covers data consistency and concurrency trade-offs under high load.

### Scope
Topics include explicit versus implicit transactions, isolation levels (Read Uncommitted, Read Committed, Repeatable Read, Serializable, Snapshot), deadlocks, and row versioning.

### Content Guidelines
Document lock escalation behaviors, deadlock graph analysis, isolation anomaly matrices (dirty reads, phantom reads), and optimistic concurrency implementation.
