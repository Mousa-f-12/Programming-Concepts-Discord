# Transact-SQL (T-SQL) Programming

### Purpose
Located within [Microsoft SQL Server](..), this directory serves as the primary repository for T-SQL language syntax, set-based query constructs, and procedural scripting in Microsoft SQL Server. It houses core procedural and relational querying knowledge.

### Scope
Topics include SELECT and DML syntax, Common Table Expressions (CTEs), window functions, temporary tables versus table variables, subqueries, and set operators.

### Content Guidelines
Store comprehensive technical lessons, comparative analyses, and language syntax guides detailing accurate, set-based T-SQL execution patterns.
