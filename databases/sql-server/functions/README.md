# SQL Server Functions

### Purpose
Located within [Microsoft SQL Server](..), this directory details user-defined function (UDF) types, execution characteristics, and performance impacts in SQL Server. It highlights set-based alternatives to procedural functions.

### Scope
Topics include scalar UDFs, inline table-valued functions (iTVFs), multi-statement table-valued functions (mTVFs), deterministic versus non-deterministic functions, and UDF inlining.

### Content Guidelines
Document cardinality estimation impacts of mTVFs, scalar function execution overheads, parallel execution barriers, and refactoring guidelines to set-based logic.
