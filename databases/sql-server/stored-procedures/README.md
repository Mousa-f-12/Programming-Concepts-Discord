# SQL Server Stored Procedures

### Purpose
Located within [Microsoft SQL Server](..), this directory covers modular procedural T-SQL programming, execution plan caching, and encapsulated database logic. It addresses security and performance benefits of procedural routines.

### Scope
Topics include stored procedure lifecycle, input/output parameters, return codes, dynamic SQL with `sp_executesql`, plan cache reuse, and error handling with `TRY...CATCH`.

### Content Guidelines
Document parameter sniffing mitigation in procedures, plan recompilation triggers, security encapsulation benefits, and best practices for procedural database routines.
