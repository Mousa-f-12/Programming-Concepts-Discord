# SQL Server — الإصدارات والبنية وأدوات الإدارة

## 1. مقدمة

**Microsoft SQL Server** هو نظام إدارة قواعد بيانات علائقية (Relational Database Management System - RDBMS)، يُستخدم لتخزين البيانات وتنظيمها واسترجاعها وإدارتها وتأمينها.

قبل التعامل مع SQL Server، يجب التمييز بين أربعة مفاهيم أساسية:

- **Database Engine:** محرك قاعدة البيانات المسؤول عن معالجة البيانات والاستعلامات.
- **Edition:** إصدار SQL Server الذي يحدد الإمكانيات والقيود والترخيص.
- **Instance:** بيئة تشغيل مستقلة لمحرك SQL Server.
- **Management Tools:** أدوات إدارة ومراقبة قواعد البيانات.

## 3. إصدارات SQL Server (Editions)

توفر Microsoft عدة إصدارات من SQL Server، تشترك في الأساس التقني للمحرك، لكنها تختلف في الإمكانيات وحدود الموارد والتراخيص.

### 3.1 SQL Server Express

**الغرض:** التعلم والتطبيقات الصغيرة وأحمال الإنتاج الخفيفة.

الخصائص:

- مجاني.
- محدود في استهلاك الموارد.
- يدعم حجم قاعدة بيانات محدوداً.
- لا يدعم SQL Server Agent.
- مناسب للتطبيقات الصغيرة.
- يمكن استخدامه في بيئات الإنتاج ضمن قيوده.

**متى تختاره؟**

- عند تعلم SQL Server.
- عند تطوير تطبيقات صغيرة.
- عند تشغيل قواعد بيانات لا تحتاج موارد كبيرة.
- عند نشر تطبيق بمتطلبات تشغيل محدودة.

### 3.2 SQL Server Developer

**الغرض:** التطوير والاختبار (Development & Testing).

الخصائص:

- مجاني للاستخدام غير الإنتاجي.
- يوفر إمكانيات إصدار Enterprise تقريباً.
- يدعم الميزات المتقدمة.
- مناسب لاختبار الأنظمة المعقدة.
- لا يسمح باستخدامه لتشغيل أحمال الإنتاج.

**متى تختاره؟**

- عند تطوير أنظمة كبيرة.
- عند اختبار الميزات المتقدمة.
- عند التدريب على إمكانيات SQL Server.
- عند الحاجة إلى بيئة تطوير قريبة من Enterprise.

### 3.3 SQL Server Standard

**الغرض:** أنظمة الأعمال والإنتاج (Business & Production).

الخصائص:

- إصدار تجاري مدفوع.
- حدود موارد أعلى من Express.
- يدعم SQL Server Agent.
- يوفر إمكانيات مناسبة للأنظمة التجارية.
- مناسب للعديد من أحمال الإنتاج.

**متى تختاره؟**

- عند تشغيل أنظمة شركات.
- عند الحاجة إلى موارد أكبر.
- عند الحاجة إلى جدولة المهام وإدارتها.
- عندما لا تتطلب البنية إمكانيات Enterprise.

### 3.4 SQL Server Enterprise

**الغرض:** الأنظمة المؤسسية واسعة النطاق (Enterprise Workloads).

الخصائص:

- إصدار تجاري مدفوع.
- إمكانيات متقدمة لإدارة البيانات.
- قابلية توسع عالية.
- ميزات متقدمة للتوافر العالي (High Availability).
- مناسب لأحمال العمل الكبيرة والمعقدة.

**متى تختاره؟**

- عند تشغيل أنظمة ضخمة.
- عند الحاجة إلى إمكانيات متقدمة للتوافر والاستمرارية.
- عند وجود متطلبات أداء وتوسع مرتفعة.
- عندما تحتاج المؤسسة ميزات لا يوفرها Standard.

| الخاصية | Express | Developer | Standard | Enterprise |

| الترخيص | مجاني | مجاني للتطوير | تجاري | تجاري |

## 5. ما هو SQL Server Management Studio (SSMS)؟

**SSMS** اختصار لـ SQL Server Management Studio، وهي أداة رسومية لإدارة SQL Server والتعامل مع قواعد البيانات.

من خلالها يمكن:

- الاتصال بـ SQL Server Instances.
- إنشاء قواعد البيانات وحذفها.
- إنشاء الجداول وتعديلها.
- كتابة وتنفيذ استعلامات SQL.
- إدارة Stored Procedures وViews.
- إدارة المستخدمين والصلاحيات.
- تنفيذ عمليات النسخ الاحتياطي والاستعادة.
- مراقبة أداء قواعد البيانات.

### الفرق بين SQL Server وSSMS

| SQL Server | SSMS |
|---|---|
| محرك قاعدة البيانات | أداة إدارة |
| يعالج الاستعلامات | ترسل الاستعلامات للمحرك |
| يخزن البيانات | تعرض البيانات وتديرها |
| يعمل كخدمة | برنامج بواجهة رسومية |
| يمكن تشغيله دون SSMS | يحتاج إلى محرك للاتصال به |

**الفكرة الأساسية:**

SSMS ليس محرك قاعدة بيانات، ولا يقوم مقام SQL Server. هو واجهة تستخدمها لإدارة المحرك.

## 6. ما هو SQL Server Instance؟

الـ **Instance** هي بيئة تشغيل مستقلة لمحرك SQL Server، لها إعداداتها وقواعد بيانات النظام الخاصة بها.

يمكن تثبيت أكثر من Instance على الجهاز نفسه.

### أمثلة على أسماء Instances

```text
localhost
localhost\SQLEXPRESS
.\SQLDEV
```

تفسير الأسماء:

- `localhost`: يشير إلى الجهاز المحلي.
- `SQLEXPRESS`: اسم شائع للـ Instance الافتراضية في Express.
- `SQLDEV`: مثال على اسم Instance مخصص.

### أنواع Instances

**Default Instance**

لا تحتاج إلى كتابة اسم Instance بعد اسم السيرفر.

```text
localhost
```

**Named Instance**

تحتاج إلى كتابة اسم Instance.

```text
localhost\SQLEXPRESS
```

كل Instance لها إعدادات تشغيل مستقلة، ويمكن أن تعمل عدة Instances على الجهاز نفسه.

### الاختيار حسب طبيعة الاستخدام

| الحالة | الإصدار المقترح |

- متطلبات الأداء.
- الميزات المطلوبة.
- الترخيص والميزانية.

## 9. الخلاصة (Key Takeaways)

- SQL Server هو نظام إدارة قواعد بيانات علائقية.
- Database Engine هو الجزء المسؤول عن معالجة البيانات والاستعلامات.
- Express إصدار مجاني محدود الموارد.
- Developer يوفر إمكانيات متقدمة للتطوير والاختبار فقط.
- Standard وEnterprise مخصصان للاستخدام التجاري والإنتاجي.
- SSMS أداة رسومية لإدارة SQL Server وليس محرك قاعدة بيانات.
- Instance تمثل بيئة تشغيل مستقلة لمحرك SQL Server.
- اختيار الإصدار يعتمد على المتطلبات التقنية والتشغيلية والترخيص.

**القاعدة الأساسية:**

لا تختَر الإصدار لأنه الأقوى أو الأكثر شهرة، بل اختره بناءً على احتياجات النظام والموارد والميزات المطلوبة وقيود الترخيص.
