# SQL Server Query Optimization

### Purpose
Located within [Microsoft SQL Server](..), this directory details execution plan interpretation, cost-based optimizer operations, and query tuning methodologies in SQL Server. It helps diagnose and remediate slow-running queries.

### Scope
Topics include graphical execution plans, operator analysis (Index Seek vs. Scan, Nested Loops, Hash Match, Merge Join), parameter sniffing, plan caching, and Query Store.

### Content Guidelines
Document execution plan warnings (implicit conversions, spills to tempdb), optimizer hint usage (`RECOMPILE`, `OPTIMIZE FOR`), and systematic query refactoring steps.
