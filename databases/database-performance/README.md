# Database Performance & Scalability

### Purpose
Part of the [Databases & Data Persistence](..) domain, this directory addresses server-level and database-level optimization strategies to maximize throughput and minimize latency. It focuses on operational scaling of data stores.

### Scope
Topics include connection pooling, read/write replicas, table partitioning, memory grants, tempdb contention, statistics maintenance, and buffer pool optimization.

### Content Guidelines
Store server-level bottleneck troubleshooting guides, hardware sizing parameters, partition switching mechanics, and maintenance job best practices.
