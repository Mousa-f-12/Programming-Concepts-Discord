# Relational Database Design

### Purpose
Part of the [Databases & Data Persistence](..) domain, this directory explores schema architecture, data integrity rules, and structural normalization principles for relational databases. It focuses on modeling schemas that scale cleanly.

### Scope
Topics include normalization forms (1NF through BCNF), denormalization trade-offs, primary/foreign key modeling, surrogate versus natural keys, and referential integrity constraints.

### Content Guidelines
Document entity-relationship modeling guidelines, data migration schemas, schema versioning strategies, and domain-driven persistence mapping patterns.
