# Databases & Data Persistence

### Purpose
This domain centralizes knowledge on relational database systems, SQL query mechanics, schema modeling, and data access layers. It provides the foundation for designing consistent, high-performance data storage solutions.

### Scope
Topics include relational schema design, Microsoft SQL Server internals, T-SQL scripting, indexing topologies, query execution engines, and Entity Framework Core integration.

### Content Guidelines
Store database normalization standards, query performance tuning benchmarks, locking and isolation analysis, and data access optimization techniques for backend systems.
