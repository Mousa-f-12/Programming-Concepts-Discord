# Entity Framework Core (Database Perspective)

### Purpose
Part of the [Databases & Data Persistence](..) domain, this directory analyzes Entity Framework Core from a database optimization, schema generation, and query translation standpoint. It addresses the relational database impact of ORM usage.

### Scope
Topics include migration management, relational mapping via the Fluent API, raw SQL execution, index generation, N+1 query detection at the database layer, and batch updates.

### Content Guidelines
Document database schema drift prevention, migration rollbacks, compiled models, and translation analysis between LINQ queries and generated SQL dialects.
