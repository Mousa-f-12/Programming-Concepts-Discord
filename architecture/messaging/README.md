# Messaging & Event Streaming

### Purpose
Part of the [Software Architecture](..) domain, this directory focuses on message broker topologies, communication semantics, and asynchronous transport infrastructure in backend ecosystems. It examines reliable asynchronous message passing between decoupled services.

### Scope
Topics include publish/subscribe models, point-to-point queues, dead-letter exchanges, competing consumers, message deduplication, and broker technologies such as RabbitMQ, Azure Service Bus, and Apache Kafka.

### Content Guidelines
Document queue topology configurations, delivery guarantees (at-least-once vs. exactly-once semantics), broker backpressure handling, and enterprise messaging integration within .NET applications.
