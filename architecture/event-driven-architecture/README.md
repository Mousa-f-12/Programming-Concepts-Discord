# Event-Driven Architecture

### Purpose
Part of the [Software Architecture](..) domain, this directory covers decoupled, asynchronous architectures that produce, detect, and consume state change events across system components. It highlights event-centric communication that maximizes service autonomy and temporal decoupling.

### Scope
Topics include domain events, event sourcing, Command Query Responsibility Segregation (CQRS), transactional outbox patterns, idempotent event consumers, and event schema governance.

### Content Guidelines
Store architectural specifications, event contract versioning rules, event ordering guarantees, and integration models between autonomous bounded contexts.
