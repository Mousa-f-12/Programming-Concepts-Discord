# Architectural Resilience

### Purpose
Part of the [Software Architecture](..) domain, this directory addresses fault-tolerant system design, preventing cascading failures across interconnected backend services. It provides patterns and policies to keep systems operational during partial outages.

### Scope
Topics include circuit breakers, retry policies with exponential backoff and jitter, bulkhead isolation, rate limiting, graceful fallbacks, and health check monitoring.

### Content Guidelines
Store fault-injection analysis, SLA protection strategies, transient error mitigation techniques, and integration patterns using resilience libraries such as Polly in .NET.
