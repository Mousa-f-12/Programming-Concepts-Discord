# Authorization & Access Control

### Purpose
Part of the [Application & Infrastructure Security](..) domain, this directory details permissions management, access rights enforcement, and privilege boundaries in software systems. It ensures subjects only perform permitted actions.

### Scope
Topics include Role-Based Access Control (RBAC), Attribute-Based Access Control (ABAC), Policy-Based Access Control (PBAC), Principle of Least Privilege, and tenancy isolation.

### Content Guidelines
Document fine-grained authorization schemas, privilege escalation prevention, access control matrices, and multi-tenant security boundaries.
