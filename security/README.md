# Application & Infrastructure Security

### Purpose
This domain provides comprehensive security standards, threat mitigation strategies, and defensive engineering practices for backend architectures. It ensures software systems protect data and resist malicious attacks.

### Scope
Topics include identity verification, access governance, token cryptography, API hardening, OWASP Top 10 mitigation, and cryptographic primitives.

### Content Guidelines
Store threat modeling templates, security hardening checklists, regulatory compliance patterns, and secure coding practices across the .NET backend.
