# JSON Web Tokens (JWT) & Token Security

### Purpose
Part of the [Application & Infrastructure Security](..) domain, this directory details compact, URL-safe token structures used for claim exchange, authentication assertion, and delegated authorization. It covers token validation and lifecycle management.

### Scope
Topics include JWT header/payload/signature structure, signing algorithms (RS256 vs. HS256), token expiration, sliding sessions, refresh token rotation, and token revocation lists.

### Content Guidelines
Document token validation vulnerabilities (none algorithm attacks, key confusion), claim payload size constraints, distributed token revocation, and secure token storage.
