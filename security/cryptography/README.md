# Cryptography & Data Protection

### Purpose
Part of the [Application & Infrastructure Security](..) domain, this directory covers mathematical encryption techniques, data integrity validation, and cryptographic key management in backend systems. It protects data confidentiality and authenticity.

### Scope
Topics include symmetric encryption (AES-GCM), asymmetric encryption (RSA, ECC), cryptographic hashing (SHA-256, SHA-3), HMAC, digital signatures, and ASP.NET Core Data Protection.

### Content Guidelines
Document cryptographic key rotation procedures, secure random number generation (`RandomNumberGenerator`), data-at-rest encryption, and transport layer security configurations.
