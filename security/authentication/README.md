# Authentication Concepts

### Purpose
Part of the [Application & Infrastructure Security](..) domain, this directory explores fundamental principles and protocols used to verify the identity of users, services, and devices. It establishes the baseline for identity assurance.

### Scope
Topics include multi-factor authentication (MFA), password hashing algorithms (Argon2id, PBKDF2, BCrypt), federated identity (OAuth 2.0, OpenID Connect, SAML), and credential lifecycles.

### Content Guidelines
Document secure password storage configurations, token exchange workflows, authentication session management, and brute-force mitigation strategies.
