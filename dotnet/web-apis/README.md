# Web APIs in ASP.NET Core

### Purpose
Part of the [.NET Platform & Ecosystem](..) domain, this directory covers RESTful API construction, Minimal APIs, controller-based endpoints, and API contract design in .NET. It details building high-performance HTTP service boundaries.

### Scope
Topics include Minimal APIs versus MVC Controllers, model binding and validation, content negotiation, OpenAPI/Swagger specifications, API versioning, and HTTP status code semantics.

### Content Guidelines
Document endpoint mapping performance, custom model binders, ProblemDetails error formats, rate limiting policies, and enterprise API contract guidelines.
