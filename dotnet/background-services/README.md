# Background Services & Hosted Workloads

### Purpose
Part of the [.NET Platform & Ecosystem](..) domain, this directory covers long-running asynchronous processes, scheduled batch jobs, and queue worker architectures hosted in .NET applications. It addresses background task orchestration.

### Scope
Topics include `IHostedService`, `BackgroundService`, scoped service resolution within singletons, graceful shutdown handling, channels (`System.Threading.Channels`), and worker services.

### Content Guidelines
Document thread pool management in workers, backpressure management with channels, crash recovery, and enterprise background job patterns.
