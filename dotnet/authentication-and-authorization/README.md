# .NET Authentication and Authorization

### Purpose
Part of the [.NET Platform & Ecosystem](..) domain, this directory focuses on identity verification, credential validation, and access governance mechanisms within ASP.NET Core applications. It ensures backend resources are properly protected.

### Scope
Topics encompass authentication schemes, authorization policies, claims transformation, cookie authentication, JWT validation, role-based access control, and endpoint authorization middleware.

### Content Guidelines
Store security architecture guides, custom authorization requirement implementations, claims mapping patterns, and integration specifications for identity providers.
