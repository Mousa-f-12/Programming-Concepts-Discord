# ASP.NET Core Authorization

### Purpose
Located within [Authentication and Authorization](..), this directory covers access control policy evaluation, permissions enforcement, and resource protection in ASP.NET Core. It governs what authenticated identities are permitted to do.

### Scope
Topics include policy-based authorization, `IAuthorizationHandler`, `IAuthorizationRequirement`, resource-based authorization (`IAuthorizationService`), roles, and the `[Authorize]` attribute.

### Content Guidelines
Document custom authorization handler design, dynamic permission checks, imperatively evaluated authorization, and attribute versus endpoint-level policy enforcement.
