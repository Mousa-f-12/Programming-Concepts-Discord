# ASP.NET Core Authentication

### Purpose
Located within [Authentication and Authorization](..), this directory details identity verification handlers, credential challenges, and authentication ticket management in ASP.NET Core. It covers validating user and client identities.

### Scope
Topics include `AuthenticationHandler<TOptions>`, cookie handlers, JWT bearer handlers, OpenID Connect flows, multi-scheme authentication, and external authentication providers.

### Content Guidelines
Document authentication ticket generation, token validation parameters, scheme forwarding rules, and secure token refresh flows in .NET backend services.
