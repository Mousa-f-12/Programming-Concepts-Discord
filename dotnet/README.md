# .NET Platform & Ecosystem

### Purpose
This domain centralizes knowledge on the .NET runtime (CoreCLR), the Base Class Library (BCL), ASP.NET Core, and application framework components. It covers the runtime environment powering modern backend applications.

### Scope
Topics span CLR fundamentals, ASP.NET Core web architecture, API design, dependency injection, runtime configuration, logging, middleware pipelines, Entity Framework Core, background processing, and runtime performance.

### Content Guidelines
Store platform architecture diagrams, hosting models, runtime release updates, enterprise framework best practices, and runtime profiling guides.
