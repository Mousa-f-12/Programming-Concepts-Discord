# Entity Framework Core (Application Layer)

### Purpose
Part of the [.NET Platform & Ecosystem](..) domain, this directory covers object-relational mapping (ORM) patterns, change tracking, and data access implementation within .NET application code. It focuses on effective developer usage of EF Core.

### Scope
Topics include `DbContext` lifecycle, change tracker internals, lazy versus eager versus explicit loading, query splitting, interceptors, and value converters.

### Content Guidelines
Document `DbContextPool` utilization, disconnected entity graphs, concurrency tokens, execution strategy retries, and clean architectural repository/query implementations.
