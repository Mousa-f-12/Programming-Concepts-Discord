# .NET Runtime Fundamentals

### Purpose
Part of the [.NET Platform & Ecosystem](..) domain, this directory details the execution model of the Common Language Runtime (CoreCLR), JIT compilation, and assembly loading. It covers the foundational runtime layer of .NET.

### Scope
Topics include the Common Intermediate Language (CIL), tiered JIT compilation, ReadyToRun (R2R), Native AOT, assembly binding, and the Unified Type System.

### Content Guidelines
Store runtime execution diagrams, IL disassembly notes, JIT tiering optimization mechanics, and foundational runtime specifications.
