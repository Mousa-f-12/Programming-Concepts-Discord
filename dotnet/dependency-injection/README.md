# .NET Dependency Injection (DI)

### Purpose
Part of the [.NET Platform & Ecosystem](..) domain, this directory focuses on the built-in Inversion of Control (IoC) container, service registration, and object lifecycle management in .NET. It guides clean architectural decoupling.

### Scope
Topics include service lifetimes (Transient, Scoped, Singleton), `IServiceProvider`, `IServiceCollection`, captive dependencies, scope validation, and factory registrations.

### Content Guidelines
Document container resolution mechanics, anti-pattern detection (service locator, memory leaks from singletons holding scoped services), and modular registration extension methods.
