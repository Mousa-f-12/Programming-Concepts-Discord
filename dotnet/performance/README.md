# .NET High-Performance Engineering

### Purpose
Part of the [.NET Platform & Ecosystem](..) domain, this directory addresses advanced runtime optimization, memory allocation reduction, and latency minimization in .NET applications. It focuses on maximizing throughput under heavy enterprise workloads.

### Scope
Topics include Garbage Collector (GC) generations and tuning (Workstation versus Server GC), object pooling (`ArrayPool<T>`, `ObjectPool<T>`), BenchmarkDotNet profiling, and hardware intrinsics.

### Content Guidelines
Store allocation profiling reports, GC pause time optimization strategies, SIMD vectorization guides, and zero-allocation code patterns for latency-critical paths.
