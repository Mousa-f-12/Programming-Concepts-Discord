# ASP.NET Core Architecture

### Purpose
Part of the [.NET Platform & Ecosystem](..) domain, this directory explores the core hosting engine, request processing lifecycle, and server abstractions of ASP.NET Core. It provides insight into the web host infrastructure.

### Scope
Topics include the generic host (`IHostBuilder`, `WebApplication`), Kestrel web server internals, request pipeline initialization, environment management, and HTTP context lifecycles.

### Content Guidelines
Document application startup mechanics, hosting configurations (in-process versus out-of-process in IIS, containerized Kestrel), socket transport pipelines, and server benchmarking.
