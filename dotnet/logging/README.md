# Logging & Diagnostics in .NET

### Purpose
Part of the [.NET Platform & Ecosystem](..) domain, this directory explores structured logging, telemetry capture, and diagnostic source instrumentation in .NET backend systems. It provides visibility into application runtime behavior.

### Scope
Topics include `ILogger<T>`, logging providers (Console, Serilog, OpenTelemetry), structured message templates, log levels, scopes (`BeginScope`), and high-performance source-generated logging (`LoggerMessageAttribute`).

### Content Guidelines
Document zero-allocation structured logging, sensitive data redaction, distributed correlation ID propagation, and integration with enterprise observability platforms.
