# Exception Handling

### Purpose
Part of the [C# Language Domain](..), this directory focuses on structured error handling, runtime stack unwinding, and defensive fault isolation in C#. It promotes resilient execution without masking unexpected failures.

### Scope
Topics include `try-catch-finally` blocks, exception filters (`when`), custom domain exceptions, aggregate exception unwrapping, and the `ExceptionDispatchInfo` class.

### Content Guidelines
Document the performance costs of exception throwing, guidelines for exceptional versus flow-control scenarios, stack trace preservation, and structured logging of error contexts.
