# C# Generics

### Purpose
Part of the [C# Language Domain](..), this directory covers parameterized types, compile-time type safety, and runtime specialization in the C# language. It explains how generics maximize code reuse and eliminate boxing overhead.

### Scope
Topics include generic classes, interfaces, and methods, generic type constraints (`where T : class`, `new()`, `struct`), covariance and contravariance (`in`/`out`), and open versus closed generics.

### Content Guidelines
Document JIT compilation behaviors for generic value versus reference types, code bloat considerations, interface variance rules, and patterns for generic service dispatch.
