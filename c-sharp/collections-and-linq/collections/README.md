# C# Collections Hierarchy

### Purpose
Located within [Collections and LINQ](..), this directory details concrete collection implementations, interfaces, and specialized memory structures provided by the .NET runtime. It guides optimal collection selection based on access patterns.

### Scope
Topics include `List<T>`, `Dictionary<TKey, TValue>`, `HashSet<T>`, `LinkedList<T>`, `Queue<T>`, `Stack<T>`, concurrent collections (`ConcurrentDictionary<TKey, TValue>`), and immutable collections.

### Content Guidelines
Document collection lookup complexities, resizing behaviors, hash collision resolution algorithms, and structural selection criteria for high-throughput scenarios.
