# Language Integrated Query (LINQ)

### Purpose
Located within [Collections and LINQ](..), this directory focuses on declarative querying syntax, expression tree translation, and query operator mechanics in C#. It highlights expressive data transformations and database query synthesis.

### Scope
Topics include deferred versus immediate execution, standard query operators, custom LINQ operators, `IEnumerable<T>` versus `IQueryable<T>`, and lambda closure allocations.

### Content Guidelines
Document LINQ performance overheads, expression-tree parsing for ORMs, allocation-reduction strategies in hot paths, and query execution lifecycle details.
