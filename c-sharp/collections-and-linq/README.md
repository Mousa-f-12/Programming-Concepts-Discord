# Collections and LINQ

### Purpose
Part of the [C# Language Domain](..), this directory explores C# collection hierarchies, data structures, and the declarative Language Integrated Query (LINQ) engine. It covers efficient data manipulation and querying in memory.

### Scope
Topics span generic collections, specialized thread-safe collections, memory-efficient collection representations, and LINQ deferred execution pipelines.

### Content Guidelines
Store algorithmic time complexity references, iterator state machine behavior (`yield return`), LINQ query optimization, and memory allocation audits for collections.
