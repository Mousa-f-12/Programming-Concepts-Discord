# Memory Management in C#

### Purpose
Part of the [C# Language Domain](..), this directory explores language-level constructs and low-overhead primitives designed for efficient memory allocation and lifetime tracking. It focuses on achieving near-zero allocation in performance-critical code.

### Scope
Topics include stack allocation (`stackalloc`), `Span<T>`, `ReadOnlySpan<T>`, `Memory<T>`, `ref struct`, pointer types, and resource disposal via `IDisposable` and `IAsyncDisposable`.

### Content Guidelines
Store documentation on zero-allocation string parsing, slice mechanics, unmanaged resource cleanup patterns, and language-level interop with memory buffers.
