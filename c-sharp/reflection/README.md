# Reflection and Metadata

### Purpose
Part of the [C# Language Domain](..), this directory explores runtime metadata inspection, dynamic type invocation, and assembly introspection in C#. It examines meta-programming capabilities alongside their performance trade-offs.

### Scope
Topics include the `System.Type` API, custom attributes, assembly loading (`AssemblyLoadContext`), dynamic method invocation, and runtime code generation with `Emit`.

### Content Guidelines
Document performance bottlenecks of runtime reflection, cached reflection delegates, Ahead-of-Time (AOT) trimming compatibility issues, and metadata extraction patterns.
