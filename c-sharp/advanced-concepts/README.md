# Advanced C# Concepts

### Purpose
Part of the [C# Language Domain](..), this directory explores specialized, high-performance, and meta-programming features of the C# language. It focuses on modern capabilities that empower developers to write expressive, low-overhead code.

### Scope
Topics include pattern matching, source generators, unsafe code and pointer manipulation, records and init-only setters, expression trees, function pointers, and compiler lowering.

### Content Guidelines
Document advanced syntax mechanics, performance implications of modern language constructs, Intermediate Language (IL) generation behaviors, and compile-time metaprogramming strategies.
