# Delegates and Events

### Purpose
Part of the [C# Language Domain](..), this directory explores type-safe function pointers, multicast invocation lists, and event subscription models in C#. It explains decoupled notification patterns within the language.

### Scope
Topics include `Action`, `Func`, custom delegates, multicast delegate mechanics, the `EventHandler` pattern, event accessors (`add`/`remove`), and event-driven decoupling.

### Content Guidelines
Document memory leak risks from unmanaged event subscriptions, weak event patterns, thread-safe event invocation, and performance comparisons between delegates and direct method calls.
