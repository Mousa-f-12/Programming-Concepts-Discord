# C# Language Fundamentals

### Purpose
Part of the [C# Language Domain](..), this directory establishes foundational language syntax, primitive types, and core semantic rules of C#. It serves as the baseline reference for writing correct and idiomatic C# code.

### Scope
Topics include value types versus reference types, nullable reference types, control flow statements, variable scoping, type casting, and operator behaviors.

### Content Guidelines
Store fundamental type system documentation, Common Type System (CTS) mapping, operator overloading rules, and basic syntax conventions for clean C# codebases.
