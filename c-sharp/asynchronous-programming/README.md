# Asynchronous Programming in C#

### Purpose
Part of the [C# Language Domain](..), this directory covers asynchronous execution paradigms, state machine mechanics, and non-blocking I/O programming in C#. It establishes best practices for writing responsive and scalable backend code.

### Scope
Encompasses async/await syntax, synchronization contexts, task scheduling, cooperative cancellation, thread pool interactions, and asynchronous streams (`IAsyncEnumerable`).

### Content Guidelines
Store best practices for avoiding deadlocks, thread pool starvation prevention, asynchronous pipeline design, and state machine overhead trade-offs.
